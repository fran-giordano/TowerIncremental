# TowerIncremental

Tower defense **incremental** en 3D hecho en Unity. Cada partida termina en derrota, pero cada derrota te hace más fuerte.

> 🚧 En desarrollo, sin fechas. Nació como trabajo práctico de Computação Gráfica (UPF, 2026); la versión original está documentada en [docs/tp-original.md](docs/tp-original.md).

## Abrir el proyecto
1. Instalá **Unity 6000.3.28f1** desde Unity Hub.
2. Cloná el repo (recomendado: [GitHub Desktop](https://desktop.github.com/)).
3. Unity Hub → *Add* → elegí la carpeta del repo.
